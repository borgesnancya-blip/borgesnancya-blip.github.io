CI/CD Pipeline Configurations

Estructura de Ramas del Repositorio

La canalización de despliegue utiliza una arquitectura de ramas protegidas para asegurar la calidad de los modelos semánticos en producción.

🌿 main (Rama de Producción - Conectada directamente al Workspace oficial de Fabric)
    └── Sincronización automática de tableros listos para el consumo corporativo.
🌿 develop (Rama de Desarrollo - Pruebas locales y validaciones)
    └── Rama donde se confirman commits locales previos al pull request final.

Código de Automatización (GitHub Workflow Agent)

Ejemplo del archivo YAML configurado en la carpeta .github/workflows/sync-fabric.yml para avisar a Fabric de nuevos commits estables.

name: Sync Power BI with Microsoft Fabric
on:
  push:
    branches:
      - main
jobs:
  sync_and_deploy:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository Code
        uses: actions/checkout@v4
      - name: Setup Node Agent Environment
        uses: actions/setup-node@v4
        with:
          node-version: '24'
      - name: Notify Microsoft Fabric Workspace
        run: |
          echo "Disparando despliegue seguro..."
          curl -X POST -H "Authorization: Bearer ${{ secrets.FABRIC_PAT_TOKEN }}" \
          https://api.powerbi.com/v1.0/myorg/groups/${{ secrets.FABRIC_WORKSPACE_ID }}/git/sync
          echo "Sincronización de Metadatos completada."

Especificaciones de Control de Stock

Modelado Dimensional (Esquema de Estrella)

Implementación de relaciones físicas 1:N unidireccionales para garantizar velocidad y consistencia de filtros.

Fact Table: fVentas (Métricas de transacciones, ingresos, costos)
Dimension Tables: dProductos (Categorías), dTienda (Sucursales), dCalendario (Lógica temporal), dFuncionario (Vendedores), fMetas (Metas de venta).

Lógica de Negocios en DAX Avanzado

Para medir la eficiencia logística, se desarrolló una métrica personalizada para transformar promedios de horas decimales en un string de tiempo estructurado HH:MM:SS.

Tiempo_Entregas (hh:mm:ss) =
VAR v_TiempoTotal = [TiempoMedioEntregas(horas)]
VAR v_Horas = INT(v_TiempoTotal)
VAR v_MinutosDecimales = (v_TiempoTotal - v_Horas) * 60
VAR v_Minutos = INT(v_MinutosDecimales)
VAR v_Segundos = ROUND((v_MinutosDecimales - v_Minutos) * 60, 0)
RETURN CONVERT(v_Horas & v_Minutos & v_Segundos, INTEGER)

DAX: Relaciones Activas con dCalendario

Dado que fVentas contiene múltiples fechas (Venta vs. Entrega), se usó USERELATIONSHIP para habilitar filtros de tiempo precisos en base a la logística.

Cantidad_Entregas =
CALCULATE(
[Cantidad_Pedidos],
USERELATIONSHIP(fVentas[Fecha_entrega], dCalendario[Date])
)

Especificaciones del Análisis RFM

Ingeniería de Datos en Origen (SQL Server)

La lógica de segmentación se ejecuta en el motor de base de datos SQL utilizando expresiones de tabla comunes (CTEs) y funciones de ventana. Esto optimiza el rendimiento del informe y evita sobrecargar la memoria de Power BI.

WITH Calculo_RFM AS (
  SELECT
    Cliente,
    Total_Ordenes,
    Total_Gastado,
    DATEDIFF(day, Ultima_Compra_Cliente, Ultima_Fecha_Global) AS Recency,
    NTILE(4) OVER (ORDER BY Total_Gastado DESC) AS Segmento_Valor
  FROM Resumen_Ventas
)
SELECT *,
CASE
  WHEN Segmento_Valor = 1 AND Recency <= 60 THEN 'Sin acción necesaria, mantener fidelizados.'
  WHEN Segmento_Valor = 1 AND Recency > 60 AND Recency <= 210 THEN 'Llamada personal y oferta exclusiva de retención.'
  WHEN Segmento_Valor = 1 AND Recency > 210 THEN 'Campaña agresiva de reactivación (Win-back).'
  WHEN Segmento_Valor IN (2, 3) AND Recency <= 90 THEN 'Ofrecer Cross-selling o Upselling para subir ticket.'
  WHEN Segmento_Valor IN (2, 3) AND Recency > 90 THEN 'Enviar recordatorio o cupón de descuento temporal.'
  ELSE 'Enviar boletín general, baja prioridad de inversión.'
END AS Accion_Recomendada
FROM Calculo_RFM

Especificaciones de Churn Analytics

Control de Métricas de Riesgo

Implementación de un modelo de puntuación interactiva cruzando la frecuencia de inactividad financiera y quejas operativas en el banco digital para calcular el "Riesgo Score".

Métricas Clave del Tablero:
- Churn Rate actual: 16.07% frente a la meta < 15.00%.
- Fractura de ingresos por fuga: 27.49% (Porcentaje total de cartera bajo riesgo directo).
- Alerta Riesgo Score = (Meses Inactivo * 1.5) + (Reclamos Promedio * 2.0).

Uso en Negocios y Resultados

Permite a los directores comerciales de banca digital filtrar por perfil académico y segmentar carteras de alto patrimonio para realizar llamadas de retención proactiva antes de registrarse la fuga del capital.

Lógica de Rentabilidad en DAX Avanzado

Cálculo dinámico de margen operativo y lucro líquido por categorías de producto y regiones.

Lucro = [Facturacion Liquida] - [Costo Total]
Lucro% = DIVIDE([Lucro], [Facturacion Liquida], 0)
Facturacion Media Mensual =
AVERAGEX(
  VALUES(dCalendario[mes_año]),
  [Facturacion Liquida]
)

DAX de Agregaciones Avanzadas

Cálculo dinámico del promedio de permanencia por departamento:

AVERAGEX(
  FILTER(dFuncionario, dFuncionario[Status] = "Activo"),
